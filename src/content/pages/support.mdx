## Sponsor the work

Inferogenesis is self-funded. Sponsorship goes through
[GitHub Sponsors](https://github.com/sponsors/DanBoringName).

## Report a problem

cpomdp and warrantlib share one repository. Bugs and feature requests for either go to
[its issue tracker](https://github.com/inferogenesis/cpomdp/issues). A fault on this site
goes to [the site's tracker](https://github.com/inferogenesis/inferogenesis.com/issues/new/choose).
It has one form for a page that renders wrong and one for a claim that is wrong or stale.

## Contribute code

Start with the
[cpomdp contribution guide](https://github.com/inferogenesis/cpomdp/blob/main/CONTRIBUTING.md).
It sets the bar for a pull request. Changes follow Fowler's refactoring practices and the
SOLID principles. Work in the linear-Gaussian case is tested against an exact oracle where
one exists. Names spell out their role, with the algebra's letter beside them.

Open an issue before anything beyond a small fix, so the design is agreed before the code.
Commit messages follow Conventional Commits.

cpomdp and warrantlib are MIT. This site's code is MIT and its content is CC BY 4.0.

## Cite the work

Each project page ends with a BibTeX record. It cites the pinned release.
